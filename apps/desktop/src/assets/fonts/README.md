# Bundled font assets

The Sarasa Gothic SC files in this directory are CJK-focused WOFF2 subsets of
the official `SarasaGothicSC` TTF release. They are used after Inter in the
global UI font stack so Inter remains the primary Latin font while CJK glyphs
use a consistent bundled fallback.

- Source: https://github.com/be5invis/Sarasa-Gothic
- Source release: `v1.0.41`
- Source archive: `SarasaGothicSC-TTF-1.0.41.7z`
- License: SIL Open Font License 1.1, see `SarasaGothicSC-OFL.txt`
- Subset format: WOFF2
- Included weights: Regular (400), SemiBold (600), and Bold (700)

The subsets retain basic Latin, punctuation, symbols, kana, and CJK Unified
Ideographs, including the common CJK extensions used by the application.
